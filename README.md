# 공유가계부 💕

지은과 홍균이 각자의 수입·지출을 기록하고 서로 공유하며 절약하는 아이폰용 웹앱(PWA).

```
[아이폰 PWA (docs/)] ──fetch──> [Apps Script API (apps-script/)] ──> [구글 시트]
   GitHub Pages                    doPost + 비밀번호 확인              내역 · 카테고리 · 예산
```

## 폴더 구조
| 경로 | 내용 |
|---|---|
| `apps-script/Code.gs` | 서버(API). 구글 시트의 Apps Script 편집기에 붙여넣는 코드 |
| `docs/` | 앱 화면. GitHub Pages가 이 폴더를 그대로 배포 |
| `docs/js/config.js` | **Apps Script 웹 앱 URL**을 넣는 곳 |
| `docs/sw.js` | 오프라인 캐시 |

## 1. 서버 설정 (최초 1회)
1. 구글 시트 → 확장 프로그램 → Apps Script → `Code.gs` 내용 붙여넣기
2. 맨 위 `INITIAL_PIN`을 비밀번호(6자 이상, 영문+숫자 권장)로 변경
3. `setup` 함수 실행 → `내역`/`카테고리`/`예산` 시트 생성 확인
4. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자)
5. 나온 URL을 `docs/js/config.js`의 `API_URL`에 입력

> ⚠️ 실제 비밀번호를 넣은 Code.gs는 GitHub에 올리지 마세요. (이 저장소의 Code.gs는 빈 자리만 있음)

## 2. 앱 배포 (GitHub Pages)
1. 이 폴더 전체를 GitHub 저장소(Public)에 올리기
2. 저장소 → Settings → Pages → Branch: `main`, 폴더: `/docs` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 로 접속

## 3. 아이폰에 설치
Safari로 접속 → 공유 버튼(□↑) → **홈 화면에 추가** → 처음 실행 시 "나는 지은/홍균" 선택 + 비밀번호 입력

## 미리보기 (데모 모드)
주소 뒤에 `?demo` 를 붙이면 서버 없이 가짜 데이터로 모든 화면을 볼 수 있어요.
예: `https://<아이디>.github.io/<저장소>/?demo`

## 수정할 때 주의
- **Code.gs를 고쳤다면**: 배포 → 배포 관리 → ✏️ 편집 → 버전: **새 버전** → 배포
  (새 배포를 만들면 URL이 바뀌니 꼭 "편집"으로!)
- **docs/ 파일을 고쳤다면**: `docs/sw.js`의 `CACHE = 'ledger-v1'` 숫자를 올려야 아이폰에 확실히 반영됨
  (반영은 앱을 한 번 껐다 켠 다음 실행부터)

## 기능
- **홈 (지금 괜찮나?)**: "평소보다 12% 덜 쓰고 있어요" 한 줄 판단, 누적 지출 페이스 차트(평소 범위 띠·지난달 점선),
  남은 기간 하루 사용 가능 금액, 월말 예상, 평소와 다른 카테고리(+원인: 횟수 vs 1회 금액), 내 예산
- **함께**: 절약 대결(각자 평소 대비 %), 평소 대비 흐름 차트, 이 달 살림 비교표, 카테고리 나비 차트
- **내역**: 전체 기간 검색(메모·카테고리·금액), 필터, 왼쪽으로 밀어 삭제
- **통계 (돌아보기)**: 자동 인사이트 문장, 카테고리별 평소 대비, 소소한 지출(1만원 미만), 월별 흐름(고정비/변동비), 지출 달력, 큰 지출
- **기록**: 자주 쓰는 항목 한 번에 입력(예: 아아 3,400), 메모 입력 시 카테고리 자동 선택
- **고정비**: 카테고리에서 '고정비'로 표시하면 절약 판단(페이스·대결)에서 빠짐
- **평소 기준**: 최근 3개월 중 기록 있는 달의 같은 날짜까지 누적 지출. 기록이 없으면 예산 합계로 대신
- **오프라인**: 인터넷이 없어도 기록 가능 → 연결되면 자동 전송
